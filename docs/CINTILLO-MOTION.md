# Crear un cintillo tipo “Motion Pieces”

Worship Graphics 0.2 incluye una plantilla integrada llamada **Motion Pieces** inspirada en la referencia animada proporcionada durante el desarrollo.

## Uso rápido
1. Abre **DISEÑO**.
2. En **Biblioteca de plantillas**, haz doble clic en **Motion Pieces**.
3. Selecciona `{{NOMBRE}}` y cambia el nombre.
4. Cada pieza tiene su propio **Entrada**, **Salida**, **Delay entrada**, **Delay salida** y **Duración**.
5. Usa **ESCALONAR 80ms** para repartir automáticamente los delays.
6. Guarda el resultado como plantilla para reutilizarlo.

## Construcción desde cero
- `+ FORMA`: rectángulos, barras y piezas de color.
- `+ IMAGEN`: texturas PNG/JPG/WebP.
- `+ TEXTO`: nombres, cargos, referencias y otros campos.
- Selecciona varias capas y pulsa **AGRUPAR**.
- Ajusta la secuencia en **Motion Timeline**.

## Presets incluidos
- Fade
- Desde izquierda / derecha / arriba / abajo
- Zoom
- Pop
- Expandir horizontal
- Expandir vertical

La combinación de presets + delay + duración permite recrear entradas por piezas sin programar.
